# Study 開發過程遇到的問題

[Study](https://andyhsuan.github.io/Study-Website/) 是給學生的 PDF 講義閱讀與手寫筆記 App，支援 iPhone、iPad 和 Apple Pencil。

這裡按時間記錄 2026-10-31 到 2026-11-09，把 App 從 Android 帶到 iOS 的十天裡，我遇到的問題。

## 開發條件本身的問題

- 我沒有 Mac，手上只有 iPhone 和 iPad。
- 每次要在手機上試，都得等雲端編譯、測試、上傳和 Apple 處理。
- 模擬器模擬不出 Apple Pencil 的手感，也看不出真實的流暢度。
- 模擬器測試偶爾會在不相關的步驟失敗。
- 雲端 macOS 的使用時間有限，每一輪都要省著用。
- 上傳失敗也會用掉一個 Build 編號，編號又只能往上加。
- 「閃一下」「有點卡」很難用文字說清楚，常常要靠螢幕錄影。

## 10/31–11/1：第一次把 App 裝上 iPhone

- 雲端模擬器第一次開機非常慢，測試常常逾時。
- 發行簽章在雲端一直卡關。
- 翻頁時畫面先糊一下才變清楚。
- Apple Pencil 偶爾完全寫不出來。
- 慢慢寫短筆畫時，筆畫會不見。
- 放大 500% 看，筆畫側邊凹凸不平，轉角有節點。
- 開啟 AI App 時，會跳到分享選單或選工作階段的畫面，內容進不了一般對話。
- 新增資料夾的輸入框會被鍵盤擋住。

## 11/1：Apple Pencil 斷筆

- 只用筆、手掌沒有碰到螢幕，整筆還是可能不出現。
- 筆畫會斷掉，要等下一筆落下，上一筆才收尾。
- 書寫感覺很卡。
- 每寫完一筆，App 就頓一下；文件越多越明顯，大約 0.1 秒。

## 11/2–11/3：第一次送審

- App Store 第一次審核要求補實機錄影和說明。
- 對話框會被鍵盤蓋住。
- 文字欄位有時候叫不出鍵盤。
- 受保護的 PDF 無法插入頁面。

## 11/3–11/4：輸入、大檔案與翻譯

- 寫完字之後回到輸入框，鍵盤叫不出來，只剩快捷列。
- 螢光筆書寫時顏色發白，蓋過底下的黑色筆跡。
- 600 多頁的 PDF 插入頁面會失敗，還跳回第一頁。
- 翻譯結果出現大量重複字和亂碼。
- 專有名詞翻錯，例如 sinusoid 被翻成「線性」，甚至「羚羊」。
- 點預覽縮圖後，畫面跳到下一頁。
- 工具列的頁碼在滑動時閃爍。
- 花了時間嘗試把整個 App 改成全原生，最後沒有採用。

## 11/5–11/7：功能變多之後

- 考試和課表的原生表單，在旋轉或不同視窗大小時版面會亂。
- iPad 的視窗模式有時不允許旋轉。
- 形狀的填色色票有時打不開。
- 手繪圖形被辨識得不準，一般手寫字也要避免被誤判。
- 錄音的播放進度和版面不穩定。
- 雙指縮放時，頁面間距會跳動。
- 高倍率下寫字和移動都變慢。
- 計時器的控制項在小視窗裡互相重疊。
- 計算機的數字對不齊，內容超出面板。

## 11/8：長筆畫與計算機

- 筆畫寫得越長，筆尖越跟不上。
- 筆跡多的大檔案，捲動時一格一格的。
- 計算機的 √x、ln x 等定積分算不出來。
- 括號後面按次方，結果不對。
- 還沒按等號，答案欄就顯示 0。
- 點算式裡的小字指數，整個畫面會縮放。

## 11/8–11/9：滑動流暢度

這是花最多時間的部分，前後 23 個版本。

**滑動**

- 頁面上只要有一筆筆跡，整頁滑動就變卡。
- 手指拖動時有階梯感。
- 只滑一點點，畫面就閃。
- 滑動時筆跡畫質切換得很明顯。
- 有螢光筆的頁面卡太久，看起來像當機。
- 頁面裡有圖片時也會卡。
- 快速滑到另一頁時會閃一下。
- 快速滑動時，畫面上下會閃出一片黑，大約 2 到 4 幀。
- 快速拖右邊的拉桿時，畫面一直黑，錄影裡有一半的幀全黑。
- 有一版滑動時頁面會左右晃，也不置中。
- 有一版右邊出現兩條滑軌。

**筆跡穩定**

- 大量書寫加快速滑動時，整片筆跡往右偏移到頁面外，大約 3 秒才回來。
- 寫完移動一下，整頁突然閃出大量錯位的筆跡。
- 寫完之後筆跡抖一下，往左或往右偏移一點點。
- 前幾筆會突然消失，又很快回來。
- 持續縮放滑動時，筆跡有時整頁閃一下。
- 畫質切換時，筆跡會變粗約 13%。

**縮放**

- 有筆跡的頁面，縮放明顯變卡。
- 寫完馬上縮放會卡住，要等幾秒。
- 有一版雙指縮放整個卡住，縮不了。

**新增頁面與其他**

- 匯入的檔案滑到底繼續上拉，新增不了頁面。
- 匯入的檔案上拉新增時，放開後畫面停約 1.2 秒。
- 短時間內連續上拉新增，會一直卡。
- 插入空白頁要卡一陣子才出現。
- 左下角偶爾跳出紅字，寫著資料庫寫入中斷。
- 第一次拒絕麥克風權限之後，再按錄音就不會再詢問。
